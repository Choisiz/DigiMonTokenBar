# 특수 진화 후 이어 키우기

- 특수 진화로 수집했고 다음 일반 진화가 있는 디지몬만 새 육성을 시작할 수 있다.
- 홈의 전구 → 진화·육성 관리 또는 해당 디지몬 상세 화면에서 `이어 키우기`를 누른다.
- 새 대상은 해당 형태에서 성장 데이터 0으로 시작한다. 일반 진화는 기존 성장 조건을 적용한다.
- 보관은 **디지몬 1개만** 가능하다. 보관 슬롯이 차 있으면 다른 개체의 새 이어 키우기를 시작할 수 없다.
- 홈 `육성 보관` → `육성 재개`는 현재 디지몬과 보관 디지몬을 맞교환한다. 형태·게이지·진화 선택·개체 프로필은 유지된다.
- **알 상태에서는 새 이어 키우기를 시작할 수 없다.** 부화 후 현재 디지몬을 보관하고 시작한다. 이전 저장 데이터에 남아 있는 보관 개체의 `육성 재개`는 복구를 위해 허용한다. 알은 보관하지 않는다.
- 일반 후속 진화가 없는 최종 형태도 육성 게이지를 100% 채워야 완료된다. 보관 개체가 있으면 형태·선택·게이지·프로필을 그대로 자동 복귀하고 보관 슬롯을 비운다. 보관 개체가 없으면 새 알로 전환한다. 완료 개체에 사용한 초과 토큰은 복귀 개체에 적용하지 않는다.
- 융합 등 특수 진화는 연출 후 노트북 등록으로 완료되며 별도 게이지를 요구하지 않는다. 그 결과로 이어 키우기를 시작한 경우에만 육성 게이지를 적용한다.
- 실제 사용 토큰은 현재 대상만 성장시킨다. 보관 중인 형태도 노트북과 융합 재료 판정에는 포함된다.
- 이어 키우기의 진화 선택에는 미수집 일반 형태로 이어지는 경로만 표시한다. 수집이 끝난 분기는 숨기고, 미수집 후속 형태로 연결되는 등록된 중간 형태는 `무료 경유`로 표시한다. 수동/자동 경유 모두 성장 게이지를 소모하지 않는다. 일반 육성의 기존 즉시 진화 규칙은 유지한다.
- 미수집 일반 후속 형태의 이름을 알림 목록에 표시한다. 이미 육성 중이거나 보관된 대상은 새 후보로 중복 표시하지 않는다.
- 파일드라몬 → 황제드라몬 드래곤모드 → 파이터모드 같은 후속 일반 루트는 육성으로 진행한다. 팔라딘모드는 별도 융합 규칙을 유지한다.

## 저장 호환

보관과 특수 진화 출처는 세이브에 포함되고 앱 재시작·내보내기·가져오기에서 유지된다. 내보내기 형식은 v3이며 이전 v1/v2 파일도 읽을 수 있다. 출처 필드가 없는 이전 세이브에서 이미 수집한 특수 진화 결과는 기존 분류 데이터로 인식한다. 새 앱이 처음 읽는 이전 원본은 `companion-state.json.before-training`에 한 번 보존된다. 이전 다중 보관·보관 알이 있는 원본은 `companion-state.json.before-training-limits`에 보존한다. 첫 번째 보관 디지몬 1개를 유지하고 나머지 디지몬의 도달 형태는 노트북 기록으로 남긴다. 보관 알은 제외한다. 이 기능을 사용한 뒤에는 최신 앱을 사용해야 한다.
